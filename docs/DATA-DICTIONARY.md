# 数据字典

| 数据 | 字段 | 规则 |
|---|---|---|
| `targets` | `beam`, `strand`, `day`, `design_kn`, `L_mm`, `R_mm`, `L_anchor`, `R_anchor` | 梁号和钢束号保留前导零；日期是班组营业日；设计力用千牛，理论伸长和锚回缩用毫米。 |
| `readings` | `id`, `beam`, `strand`, `day`, `end`, `jack`, `level`, `force`, `unit`, `stroke`, `displacement_unit` | 左/右对应 L/R，力级支持 20%、40% 和 100%，`kN` 直读、`MPa` 按证书折算。位移默认毫米，可用 cm，旧表用 `extension`。 |
| `calibrations` | `jack`, `revision`, `from`, `until`, `slope`, `offset` | 有效日 `[from,until)`，换算千牛等于压力乘斜率加截距。存在多条同日有效的证书时，该压力读数隔离。 |

数值以 Decimal 计算，结果留三位小数供查阅，判定使用舍入前数值。相同流水编号且归一后完全一致的读数算重复，字段矛盾则隔离同号整组。在同一端和力级上存在两条合格读数时，保留竞争原因并要求复测。

对齐目标力 = 设计力 × 力级。目标前后 5% 均计为合格，端点包含在内。按两个低力级的实测载荷与位移建立直线并外推到零载，峰值位移减外推零点及回缩即有效伸长。每端绝对相对偏差上限为 10%，双端总和上限为 6%。这三个上限是演示工艺合同参数，实际工序应采用项目批准的工艺标准。缺力级或位移不严格增加的端位进入待复测。工程设计值和原始记录结构损坏时拒绝整个计算。

原读数 = 对齐 + 隔离 + 重复。梁号勾稽按设计钢束逐条分类。批号由内容与规则版本共同决定；重复上传只引用既有结果。文件上限 256 KiB，每个数据组最多 1200 行。
