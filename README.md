# 预制梁张拉记录

制梁质检员上传两端的压力或载荷记录，校对力级，扣除外推初值与锚固回缩，再把钢束分成通过、超限和待复测三类。样例为虚构制梁场班组记录。

## 运行

进入项目目录，执行 `docker compose up --build -d`，访问 `http://127.0.0.1:18433/`。

1. 选择「对照钢束」，点击「复算读数」。0007/S01 左右端分别为 20 mm，合计 40 mm，并通过该样例的双端判验。
2. 切回「夜班原始记录」，比对同梁的 0007/S02。左端外推后超过单端限值，合计也超过限值。
3. 到「力级对齐」和「伸长补偿」追查源行，再打开「梁号勾稽」检查班组分类是否与钢束清单相符。
4. 点击「下载张拉证据」。其中包含班次摘要、规则、源行和判验原因；正文首字段 `证据凭证` 标注待签、有效或撤回。
5. 到「工艺复算」签发证据；勾稽有差额时复算照常可查但拒签。错签可在同一页撤回，撤回后按原凭据号仍能取回当时的读数与结论，补签会换成新号。

页面可上传同结构的 JSON，字段要求见 [数据字典](docs/DATA-DICTIONARY.md)。`POST /api/runs` 接受 JSON `{"sample":"checked"}`，或 multipart 的 `file`。其他入口列在 [深度登记](docs/DEPTH.md)。

执行 `docker compose exec -T app pytest -q` 运行回归。 `docker compose down` 停止服务并保留历史。
